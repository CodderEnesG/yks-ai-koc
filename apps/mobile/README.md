# @yks/mobile

Expo SDK 58 uygulaması (iOS + Android). Kurulum ve komutlar için kök dizindeki README'ye ve `docs/PLAN-2026-10-22-teknoloji-secimi-ve-t02.md`'ye bak.

```sh
pnpm --filter @yks/mobile ios       # dev build, iOS simülatör
pnpm --filter @yks/mobile android   # dev build, Android emülatör
pnpm --filter @yks/mobile start     # Metro (dev client açıkken)
```
